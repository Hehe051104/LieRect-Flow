核心概念：
θ: 物体绕转轴绕过的总角度
n: 物体绕着哪根转轴转
omega: = θ * n 三维空间里一根自带右手定则的箭头：它的空间朝向锁定了旋转轴，它的几何长度精确等于转过的角度。(切空间里的) 角速度 或 旋转向量

李群SO(3)：当前的静态姿态
李代数so(3)： 瞬时运动速度

1
要求 刚体不变形 推到 R为正交阵

2
由物体旋转过程中保持刚体不变形推到 R导✖️R转置 = w hat 进而 R导 = w hat ✖️ R
所以积分得 R(t) = e的(w hat ✖️ t)  w hat为3✖️3矩阵，w为列矩阵(角速度)

3 （n hat为类w hat的反对称矩阵）
w hat ✖️ t = θ("总角度") ✖️ n hat  (n hat 为定轴旋转的空间转轴方向 含义为哪根转轴)
将R(t)转换成求 e的(θ ✖️ n hat)
在算n hat 的幂时发现：n hat 的n次幂有周期特性 (反对称矩阵惊人的代数周期性质)
把 e的(θ ✖️ n hat) 泰勒展开，n hat一组，n hat²一组，正好又对应sin与cos展开
罗德里格斯公式(Rodrigues' Formula):所以 R = exp(θ ✖️ n hat) = I + sin(θ)n hat + (1 - cos(θ))n hat²

4 (全程都是R与角度速omega之间的转换)
R = I + sin(θ)n hat + (1 - cos(θ))n hat²
若已知R，反过来求θ    两边同时求tr
若要求 n 令R - R转置  ( 核心:n转置 = -n ) 求到的是n hat，再把hat脱掉得到n

θ为π的情况：旋转群 SO(3)的固有拓扑奇异性（Cut Locus，割迹）
绕转轴 n 逆时针旋转 180°，与绕相反转轴 n 顺时针旋转 180°，最终达到的物理姿态完全是同一个矩阵：  就像从北极出发到达南极有两条路，左边或右边
当要求 so3_log 反解转轴时，数学上无法判定该返回 +n 还是 -n
导致R - R转置 = 2sin(θ)nhat = 0 所有关于转轴 n 的信息在这一步全被乘零抹除了
🌟：但不用担心，工程上超级大概率不会出现旋转角度为π的情况，且根据机械臂的高频性质，相邻两帧通常在 0.01 ~ 0.05 rad 之间，即不足 3°

正向操作（罗德里格斯）： 计算机拿到 omega，先算omega模长得到 θ，再除以模长得到 n，代入公式生成旋转矩阵 R。
负责在推理时，把神经网络预测出的平坦三维速度，百分之百无畸变地还原成驱动机械臂电机的真实三维空间旋转矩阵

逆向操作（对数映射）： 计算机通过旋转矩阵 R 的迹解出 θ，通过反对称差解出 n，最后两者一乘拼回 θ * n = omega 输出给神经网络。
负责在训练时，把专家的三维旋转姿态转化为神经网络能够直接计算 Loss 的平坦三维速度
